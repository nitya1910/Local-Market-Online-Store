# Local Market Online Store for Small Vendors

## Problem Statement
A platform for local vendors to set up digital storefronts, allowing local customers to easily discover, compare, and purchase products from nearby vendors.

## Features
- Role-Based Access Control: Customer, Vendor, Admin
- Vendor Storefronts
- Product Search & Filtering
- Shopping Cart & Checkout
- Order Tracking
- Admin & Vendor Dashboards

## Prerequisites
To run this project, you will need:
- [Node.js](https://nodejs.org/) (v16+)
- [MongoDB](https://www.mongodb.com/) (Local or Atlas)
- Git (optional)

## Installation & Setup

1. **Install Node.js & npm**
   Please ensure Node.js is installed on your computer. You can check by running `node -v` and `npm -v` in your terminal.

2. **Backend Setup**
   ```bash
   cd server
   npm install
   npm run dev
   ```

3. **Frontend Setup**
   ```bash
   cd client
   npm install
   npm run dev
   ```
